# Red Point Church App V6.2 — Security & Privacy Hardening

V6.2 is a reliability/security pass, not a feature expansion.

## Changes
- Version synchronized to 6.2.0.
- Diagnostic sharing no longer includes the device's user-assigned device name; it reports only the platform category.
- Added a Supabase migration that reasserts least-privilege RLS for public leadership data.
- Added indexes for common published-content queries.
- Existing admin-only write policies remain the boundary for church-managed content.
- Visitor submissions continue to go through the server-side Edge Function rather than directly exposing service credentials to the app.
- No prayer-request feature.

## Operational requirement
Run `supabase/v6.2_security_hardening.sql` in the Supabase SQL Editor after the previous migrations.

## Security principle
The mobile app contains only public/publishable Supabase credentials. Service-role credentials must remain server-side in Supabase Edge Functions and must never be placed in the Expo app environment.
