# Red Point Church App V6.1

## App Help & Diagnostics

V6.1 adds a lightweight troubleshooting screen for real iPhone and Android testing.

It reports:
- app version and platform
- device name when available
- notification permission state
- whether Supabase/EAS configuration is present
- counts of currently loaded events, announcements and sermons
- last successful refresh
- full/partial data-load warnings

Users can refresh church information and share a non-sensitive diagnostic summary with staff. No passwords, auth tokens, or private visitor data are included.

## QA note
This is a source release. Run `npm install`, `npm run typecheck`, and an EAS development/preview build in the real project environment before treating it as a production binary.
