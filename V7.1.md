# Red Point Church App V7.1 — Live Production Verification

V7.1 moves the project from a production launch candidate toward a **real live-environment verification**. The mobile app remains feature-stable; the focus is proving that the production backend endpoints are reachable before physical-device and store testing.

### Added
- `scripts/live-production-check.mjs`
- `npm run check:live`
- Live Supabase REST smoke tests
- Live Edge Function reachability checks
- `LIVE_PRODUCTION.md` with explicit release gates

### Important
This release does **not** claim that the church's production backend has been deployed or that mobile devices have passed testing. Real credentials and real devices are required.
