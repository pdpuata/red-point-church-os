# Workflow: Sunday Readiness

## Outcome
Know whether the next Sunday service can execute without avoidable operational surprises.

## Trigger
Scheduled planning checkpoint + manual staff run.

## Inputs
Service date; roster; band; worship leader; musicians; sound engineer; media; host; sermon topic/status; setlist; song charts; lyrics; announcements; notifications; unresolved incidents.

## Rules
- Required roles must be assigned.
- Band leader must be notified within the required lead time.
- Songs must be proposed and locked according to the worship workflow.
- Media must have lyrics by rehearsal.
- Host must have final set by Saturday.
- Missing sermon/topic information is surfaced as a dependency, not silently guessed.
- Any unresolved critical issue blocks readiness.

## Loop
Observe → verify data freshness → evaluate rules → propose safe actions → request human approval for consequential actions → execute bounded actions → verify → record → escalate failures.

## Output
Readiness score, blocking issues, warnings, completed checks, recommended actions, owners, evidence IDs.
