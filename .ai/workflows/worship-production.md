# Workflow: Worship / Production

## Goal
Reduce coordination overhead while protecting pastoral, musical and production judgement.

## Canonical sequence
Roster → availability → band assignment → leader confirmation → song proposal → theological/formation review → set lock → charts/lyrics → media/host communication → rehearsal readiness → Sunday readiness → post-service review.

## AI may
Detect missing information; compare deadlines; identify roster conflicts; draft communications; assemble checklists; surface repeated problems; generate readiness reports; propose alternatives.

## Humans decide
Song theology; pastoral direction; sensitive people decisions; final worship leadership; exceptional substitutions; significant production changes.

## Repetition contract
Every run produces a durable record so the next run can start from state rather than from WhatsApp history.
