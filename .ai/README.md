# Red Point Church OS — AI Control Plane

This directory is the durable instruction layer for humans and AI agents working on the church system.

Start with:
- `constitution.md`
- `product-principles.md`
- `architecture.md`
- `domain-model.md`
- `prompts/agent-next-task.md`

Then select the relevant workflow and agent.

**Operating rule:** do not add features merely because a feature is possible. Find the expensive/painful/repetitive work and redesign the process around the desired outcome.
