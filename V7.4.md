# Red Point Church V7.4 — Guided Live Deployment

V7.4 is the deployment bridge between the production-ready project and the real Red Point Church environment.

## What changed
- Added `scripts/guided-deploy.mjs`.
- Added `npm run guided:deploy` and `npm run verify:deployment`.
- Added an explicit COMPUTER/PHONE deployment sequence.
- Added a project-integrity gate before any live deployment commands.
- Keeps server secrets out of the Expo mobile environment.
- Version is 7.4.0.

## Important
This release does **not** claim that Supabase has been deployed. The live deployment requires access to the church's real Supabase project and its production secrets.

## Run it on Windows
```powershell
npm install
npm run guided:deploy
```

The script prints the exact next command at each stage but does not execute credential-sensitive deployment steps automatically.

## Minimum live sequence
1. Create/populate `.env`.
2. Create/populate `.supabase.production.env`.
3. `npx supabase login`
4. `npx supabase link --project-ref YOUR_PROJECT_REF`
5. `npx supabase db push`
6. Deploy the four Edge Functions.
7. Configure server secrets in Supabase.
8. Create the admin Auth user and add its UUID to `admin_users`.
9. Run `npm run check:live`.
10. Run `npm run check:production-config`.
11. Build the Android preview APK.
12. Test on a real Android phone and iPhone before production store builds.

## Security rule
Do not put service-role keys, Resend API keys, or YouTube API keys in `.env`, `app.json`, source code, screenshots, or chat messages.
