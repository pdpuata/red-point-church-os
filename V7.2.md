# Red Point Church App V7.2 — Production Setup Bridge

V7.2 moves the project from a release ZIP toward a real production environment.

## Before deployment

1. Install Node.js and Git on the Windows computer.
2. Open this project folder in PowerShell.
3. Run `npm install`.
4. Run `npm run setup:production`.
5. Copy `.env.example` to `.env` and enter the real mobile-safe values.
6. Copy `.supabase.production.env.example` to `.supabase.production.env` and enter server-only values.
7. Never place service-role keys, Resend keys, or YouTube API keys in `.env`.

## Deploy the backend

After reviewing the configuration:

`npm run deploy:backend`

This links the Supabase project, pushes the database migrations, deploys all four Edge Functions, and sets the server-side secrets without printing their values.

## Verify

Run:

`npm run backend:check`

`npm run check:live`

`npm run preflight`

Then test on real iPhone and Android devices.

## Admin bootstrap

Create the staff member in Supabase Authentication, copy the Auth UUID, and add that UUID to `admin_users`. Test that the staff account can manage content and that a non-admin cannot.

## Production gate

V7.2 does not claim that Supabase, Edge Functions, email, YouTube sync, notifications, or stores are live. Those require your real production project and credentials.
