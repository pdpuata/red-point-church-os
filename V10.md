# V10 — Autonomous Runtime

Architecture now:

**Organisational State → Event → Subscription → Workflow Dispatch → Autonomous Runtime → Deterministic Handler → Verification → Outcome → Audit → Learning**

The system no longer depends on a human opening the Control Tower to notice every recurring operational condition. Supabase Cron wakes the runtime every minute. The runtime discovers the operational horizon, creates idempotent work, claims it, executes only registered safe handlers, verifies the result and escalates blockers.

The runtime is deliberately fail-closed: unsupported workflows do not receive arbitrary execution authority.
