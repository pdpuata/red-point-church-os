# Red Point Church App V6.3 — End-to-End Mobile QA

V6.3 adds a practical release-journey checklist to App Help/Diagnostics so real-device testing follows the critical public journeys: loading content, events, sermons, search, contact, visitor submission, notifications, offline recovery and reconnect.

This is a testing aid; it does not claim that a device test has been performed automatically.
