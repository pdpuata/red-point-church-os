# Red Point Church App V6.4 — Store Readiness

V6.4 turns the project into a store-submission preparation package. It adds store listing copy, a privacy-policy draft, a submission checklist, and clearer iOS photo-library permission wording.

This version deliberately does not pretend that store submission is complete: final artwork, public privacy-policy URL, developer accounts, production backend configuration and real-device testing still require church action.

Version: 6.4.0
